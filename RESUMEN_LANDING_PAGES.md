## 🎯 Cómo Usar Inmediatamente

### PASO 1: Configurar Productos
```
1. Ve a tu panel de administrador
2. Crea al menos 1-6 productos
3. Asigna categoría (tecnología, moda, hogar, etc.)
4. Configura precios y descuentos
```

### PASO 2: Acceder a tu Landing
```
1. Desde admin, copia tu slug de tienda
2. Abre: https://tudominio.com/landing/tu-slug
3. ¡Listo! Tu landing page se adapta automáticamente
```

### PASO 3: Crear Anuncio Facebook
```
1. Facebook Ads Manager
2. Objetivo: Traffic o Conversions
3. URL: https://tudominio.com/landing/tu-slug
4. Presupuesto: $10-20 USD/día
5. ¡Lanza!
```

### PASO 4: Monitorear
```
1. Facebook Ads → Performance
2. Revisa: CTR, CPC, Conversion Rate
3. Después de 3 días de datos, optimiza
```

## 🎓 ¿Necesitas Ayuda?

### Problema: Landing no carga productos
→ Revisa `/api/public/products/:slug` en consola (F12)

### Problema: Pixel no rastrea
→ Usa "Facebook Pixel Helper" extension en Chrome

### Problema: Botones no funcionan
→ Verifica que `/tienda/:slug` esté activo

### Problema: Se ve lenta
→ Usa `landing.html` en lugar de React version

### Problema: Quiero cambiar el nicho
→ Edita línea ~130 en `LandingPageNicho.tsx`
