# ⚡ QUICK START - Landing Pages en 5 Minutos

## 🎯 Objetivo
Tener tu landing page lista en **5 minutos** para empezar a vender en Facebook Ads.

---

## ✅ 5 Pasos Rápidos

### PASO 1: Accede a tu Panel Admin (1 min)
```
1. Abre: https://tudominio.com/admin
2. Inicia sesión
```

### PASO 2: Crea/Configura Productos (2 min)
```
1. Ve a "Productos"
2. Crea al menos 1-6 productos:
   - Nombre
   - Precio
   - Foto
   - Categoría (importante!)
3. Guarda
```

💡 **TIP:** Si aún no tienes productos, prueba con los de demostración

### PASO 3: Accede tu Landing Page (1 min)
```
1. Copia tu slug de tienda (ej: "mi-tienda-dropshipping")
2. Abre: https://tudominio.com/landing/mi-tienda-dropshipping
3. ¡Listo! Tu landing está lista
```

### PASO 4: Prueba en Mobile (30 seg)
```
1. En la misma página, presiona F12 (DevTools)
2. Haz click en el ícono de celular 📱
3. Verifica que se ve bien en móvil
```

### PASO 5: Lanza en Facebook (1.5 min)
```
1. Abre Facebook Ads Manager
2. Crea Campaña → Objetivo "Traffic"
3. Pega tu URL: https://tudominio.com/landing/mi-tienda-dropshipping
4. Audiencia: Tu país + interés (tech/moda/etc según nicho)
5. Presupuesto: $10 USD/día
6. ¡LANZA!
```

## 📊 Qué Esperar

### Primeras 24 horas
```
- 50-200 clicks (según presupuesto)
- CTR: 1-3%
- CPC: $0.50-1.50
```

### Primeros 3 días
```
- 150-600 clicks
- 1-3 conversiones (si funciona)
- ROAS: 1:1 a 3:1
```

### Primera semana
```
- Si ROAS > 2:1 → Aumenta presupuesto 30%
- Si ROAS < 1:1 → Revisa landing o anuncio
```

## 🔍 Monitorear en Tiempo Real

### En Facebook Ads
```
1. Tu campaña → Ver Resultados
2. Revisa diariamente:
   - Clics
   - CTR (Click-Through Rate)
   - CPC (Costo por Clic)
```

### En tu Landing
```
1. Abre: https://tudominio.com/landing/tu-tienda
2. F12 → Console
3. Busca "fbq" - Si aparece, el Pixel funciona ✅
```

---

## 🆘 Problemas Rápidos

| Problema | Solución |
|----------|----------|
| Landing no muestra productos | Verifica que creaste productos en admin |
| Landing se ve lenta | Usa /landing.html en lugar de /landing |
| Botones no funcionan | Recarga la página (Ctrl+Shift+R) |
| Pixel no rastrea | Verifica Pixel ID en configuración tienda |

## 🎯 Próximo: A/B Testing (Después de 3 días)

Si tienes datos, prueba:

### Test 1: Nicho Diferente
```
- Versión A: Landing actual
- Versión B: Cambia categoría de productos a otro nicho
- Medir: ¿Cuál convierte más?
```

### Test 2: Anuncio Diferente
```
- Versión A: Foto product
- Versión B: Foto lifestyle
- Medir: ¿Cuál tiene mejor CTR?
```

### Test 3: Presupuesto
```
- Día 1-3: $10/día (test)
- Si funciona: $20-30/día (escala)
- Si muy bien: $50+/día (maximiza)
```
